## C. Map and image accuracy checklist

- [ ] The image title, creator, date and source are recorded.
- [ ] A map of a historical kingdom is not presented as a modern political boundary.
- [ ] An archaeological reconstruction is labelled “reconstruction” where appropriate.
- [ ] A Liberation War sector map is used to explain military organisation, not to imply that every frontline remained static.
- [ ] UNESCO status is stated precisely; listing a site is not the same as UNESCO endorsing every historical claim about it.
- [ ] If an external file does not load, open its source-page link and use the credited image there.
- [ ] Any statistical chart includes the data year, unit and source; do not invent historical numerical series.
